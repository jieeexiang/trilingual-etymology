# 三语词源对照

输入一个英语、法语或荷兰语（佛兰芒语）单词，程序会：

1. 找出另外两种语言里对应的词（来自维基词典的翻译表）；
2. 为每个词画出词源链（来自维基词典的结构化词源标记）；
3. 自动判断三者的关系：英荷同源、英语借自法语、同出拉丁语，或者“日耳曼词经法语绕回英语”；
4. （可选）让 AI 根据这些数据用中文讲解，并给一个记忆窍门。

所有数据都保存在你自己的电脑上，查词不需要联网。只有 AI 讲解需要联网。

## 第一次使用

### 1. 安装 Python

需要 Python 3.10 或更新的版本。

- **Windows**：到 python.org 下载安装（新版是“Python Install Manager”）。装好后打开命令提示符，输入 `py --version`；如果提示还没有安装运行环境，运行 `py install default`，遇到提问都输入 `y`。
- **Mac**：到 python.org 下载安装，或者用 Homebrew：`brew install python`。

> **命令写法**：下面的命令在 Windows 上用 `py`，在 Mac 上用 `python3`。Windows 上如果输入 `python` 提示 “Python was not found”，那是系统自带的占位快捷方式，改用 `py` 即可。

### 2. 安装程序需要的组件

打开“命令提示符”（Windows）或“终端”（Mac），进入程序文件夹，运行：

```
py -m pip install -r requirements.txt
```

（Mac：`python3 -m pip install -r requirements.txt`）

**怎样在程序文件夹里打开命令行**：Windows 上打开 `trilingual` 文件夹，点地址栏，输入 `cmd` 回车；Mac 上在访达里右键文件夹 →“服务”→“新建位于文件夹位置的终端窗口”。

### 3. 先用样例数据试一下（1 分钟）

```
py import_data.py tests/sample.jsonl.gz
py server.py
```

浏览器会自动打开 http://127.0.0.1:8000 。样例里只有 garden、war、house、table、beef 这几组词，用来确认程序能正常运行。

### 4. 下载并导入完整的维基词典数据（只需做一次）

```
py download_data.py
py import_data.py data/raw-wiktextract-data.jsonl.gz
```

- 下载约 **2.8 GB**。如果中途断了，再运行一次会接着下载。
- 导入时会读完整个文件，只保留英语、法语、荷兰语的词条。根据电脑速度，大约需要 **半小时到一小时**，屏幕上会显示进度。
- 导入完成后会生成 `data/words.db`，大小约 1–2 GB。之后可以删掉下载的 `.gz` 文件来节省空间。
- 维基词典每周都在更新。想更新数据时，重新做这一步就行。

### 5. 以后每次使用

- **Windows**：双击 `start-windows.bat`
- **Mac**：双击 `start-mac.command`（第一次可能要在“系统设置 → 隐私与安全性”里允许运行）
- 或者在命令行运行 `py server.py`

用的时候黑色窗口要一直开着；用完后关掉它，或按 Ctrl+C。

> **Windows 11 弹出“智能应用控制已阻止可能不安全的文件”**：从网上下载的 `.bat` 文件会被拦截。可以右键 `start-windows.bat` →“属性”→ 勾选“解除锁定”；或者用记事本新建一个同名文件，内容和原文件一样；也可以直接在命令行运行 `py server.py`。

## 开启 AI 讲解（可选）

1. 到 console.anthropic.com 注册，充值少量额度，创建一个 API 密钥。
2. 把 `config.example.json` 复制一份，改名为 `config.json`。
3. 打开 `config.json`，把密钥填进去，保存。
4. 重新启动程序。

默认使用速度快、费用低的 Haiku 模型，讲解一个词大约花费不到一欧分。想换模型，就改 `config.json` 里的 `"model"`。

AI 只能看到程序从维基词典整理出的数据，并被要求不要补充数据里没有的说法。

---

## 放到服务器上

在服务器上做完第 1、2、4 步，然后运行：

```
py server.py --host 0.0.0.0 --port 8000
```

同一个网络里的其他设备（比如手机）就可以用 `http://服务器地址:8000` 访问。

如果要放到公网上，建议在前面加一层 Nginx 或 Caddy，并设置 HTTPS 和登录密码。原因是：开启 AI 讲解后，每次讲解都会用你的 API 额度，不能让陌生人随便用。

## 使用小提示

- **语言选择**：有些词在几种语言里拼写一样，比如 table、water、main。程序默认先按英语查；想按别的语言查，可以点“法”或“荷”，或者点结果上方的“按法语查”。
- **其他译法**：每一栏下面有“其他译法”按钮。程序自动挑的词不合适时，点一下就会换成那个词，关系分析也会重新计算。
- **词源原文**：每一栏都可以展开“维基词典词源原文”，自动分析拿不准的时候，直接看原文。

## 已知的局限

- 关系是根据维基词典的词源模板自动判断的。词条写得越完整，判断越准；有些词条没有结构化标记，程序会提示你去看原文。
- 释义是英文的（维基词典的英文版）。中文意思来自英语词条里的中文翻译，不是每个词都有。
- 一个词有好几个来源时（比如同形异义词），程序会选翻译最多的那个词条。

## 文件说明

| 文件 | 作用 |
|---|---|
| `download_data.py` | 下载 kaikki.org 的维基词典数据 |
| `import_data.py` | 把数据导入本地数据库 `data/words.db` |
| `etymology.py` | 生成词源链，判断三者关系 |
| `lookup.py` | 查词和挑选对应词 |
| `server.py` | 网页服务器和 AI 讲解 |
| `static/index.html` | 网页界面 |
| `tests/` | 样例数据，用来快速测试 |
